# python-projects

The project **[Alien invasion](https://github.com/entropia64x/python-projects/tree/main/Alien%20Invasion)** is a project that I wrote as an excersice from the book *Python: a Crash Course*.

The files in the folder *[pdf_toc](https://github.com/entropia64x/python-projects/tree/main/pdf_toc)* were made to get the contents of some pdf's with OCR and assign it for a better reader experience. Thery are not completely infalible, and after running the scripts some manual changes are needed, but they save hours of searching and writing titles and subtitles in a .txt file.
